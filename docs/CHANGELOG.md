# 更新记录

## v0.14.0-web — 撤离与调度

- 公交改为两站撤离任务：12秒发车准备、每站接人4秒、3秒伏击预警、劫掠车停靠攻击；5秒护航、冻结与队员拦截均可保护公交。送达按车况奖励80–160G，并使两个支援技能各减少8秒冷却。
- 分流默认多路进攻，改为8秒临时定向、18秒冷却。A快线/B慢线/C常规线影响分岔路段速度；只有岔口前的敌车换路，民车固定撤离线路，已过岔口的敌车不回头。
- 修复变道后桥梁仍检测旧位置的问题，新旧桥按车辆实际路线计算撞击、载重与破拆。偶数波加入破拆车，第6波起成对出现；桥面停留7秒破拆、低血量警报、裂纹和实时损伤显示。抢修保留60G恢复30、18秒冷却。
- 相对上一网页版，普通敌人生命约+29%、首领+50%，逐波成长1.15，每波普通车+2，计划出场间隔0.46秒，击杀奖励为原值90%并取整。保留入口车距和全部出场后5–10秒发下一波。
- 战斗增加短时通知，分流提供直接选路面板；桥梁耐久与破拆标签错开。保留960×540居中窗口和交通图册画风，微信包仍冻结在v0.13.0。
- 83项网页检查通过；48关均完成合法经济通关模拟，其中三处双路夹击关调整为两侧优先升级的布防后通过。模拟包含实际护航、分流、付费抢修和变道后的重新布防；不代表所有布防都能通关。
