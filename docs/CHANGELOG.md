# 更新记录

## v0.8.1 — 进化火力与射程调整

- 四种设施的发射、弹迹、命中与队员攻击随等级和进化分支变化；四级强化冲击波、光束与爆点表现。
- 信号连锁使用折线电弧，聚能使用直束；重弹和齐射弹采用不同飞行高度与爆破样式。
- 基础射程缩小约14%–15%，同步下调升级与远程专精加成；集合范围与显示圈一致。
- 动画使用模拟时间并在发射时保存外观快照，暂停、倍速及升级期间保持一致，不重复结算伤害。
- 53项测试通过，新增范围边界、动画与伤害分离、升级期间弹体快照和暂停回归检查；缩短射程后全部48关合法经济通关模拟通过。

## v0.8.0 — 六境变道

- 六章采用独立旋律、节奏、和弦和音色；音乐/音效独立静音，记忆偏好，新增 M 音乐快捷键。
- 基础塔简化为速射塔、信号塔、导弹塔、勤务站，48条专精改用简短名称。
- 两条专精保留不同武器轮廓，追加各章风车、水箱、散热片、履带、浮筒、根须等设备外形；进化图鉴支持六章预览。
- 水泵塔修复队员，丘陵塔削甲，海岛塔阻止护盾再生，结合原有多目标、穿甲、控制与补员形成不同配合。
- 重设计全部48关路线，增加交叉、三路夹击、蛇形与回旋布局；每章第4、8关增加一次有预告的中途变道，共12处事件。
- 新旧道路统一预留建造空间，每关31–59处地块；过岔口的旧车继续驶出，未过岔口及新车进入新路。
- 50项测试通过，覆盖变道、未来道路占地、章节音乐和新增专精机制；另对全部48关执行合法经济通关模拟，均通过。

## v0.7.0 — 交通设施重构与目录整理

- 四种防御设施重新设计为磁轨速射台、信号干扰站、巡航发射井、机动勤务站；重写全部48条章节进化命名。
- 磁轨连续锁定同车增伤，信号站周期性区域干扰，巡航弹增加抛射尾焰；勤务站派遣拦截队员。
- 采用圆角机壳、玻璃面板、工业灯带、天线和发射舱；等级及专精改变设备模块和轮廓。
- 拦截队员缩小至原绘制比例64%，更换为头盔、反光背心与护板；血条独立绘制，拦截参数保持。
- 集合点改为道路信标；修正高设备选区遮挡后方空地块中心的问题。
- 将单文件代码拆分至 src/data、src/core、src/render 等目录；CSS归入 assets，历史文档与截图归入 docs，根目录保留入口与说明。
- 普通 defer 脚本保留双击HTML运行能力，测试跟随入口依赖顺序加载，旧星级与声音偏好继续沿用。
- 43项回归测试，覆盖新设施机制、空地块点击、旧战斗机制和开局及六章终关通关模拟。

## v0.6.0 — 四塔、守卫与地貌进化

- 防御体系收敛为箭塔、法塔、重炮、兵营四种核心塔，第一关全部可用。
- 兵营派出实体守卫，靠近车辆后拦截交战；敌人反击，首领更强，阵亡后免费重训；支持地图内集合点调动。
- 六种地貌各有四塔的两条专精，共48条进化路线；通关永久研究，局内花金币选择与强化。
- 重绘四级建筑轮廓，升级增加塔身、屋顶、侧翼、旗帜、魔法晶体与多管武器，章节采用不同配色。
- 战役进化图鉴展示本章研究要求、费用、能力和两条路线的逐级外观预览；升级仍从地图点击塔进行。
- 添加无外部资源的合成战斗音效与轻量配乐，独立开关并记忆设置，暂停及后台停止声音，限制并发音量。
- 保留48关、27种敌人与定时叠波；旧星级保留，旧塔组替换为四塔，按通关进度恢复研究资格。
- 40项自动化测试通过，新增士兵交战/调动/重训、进化门槛和声音生命周期验证；通关模拟覆盖开局和六章终关。

## v0.5.0 — 六境远征与定时攻势

- 战役扩展为城市、乡村、沙漠、丘陵、海岛、森林六种地貌，每章八关，共48关、402波、12场首领战。
- 每章独立的选关图形、路网、场景装饰和敌人组合；新增抗火越野车、抗控履带车、护盾舰、补给舰、林地分裂怪等，敌人及子单位合计27种。
- 首波准备30秒，随后按20–32秒间隔连续发动，可与旧波重叠；每批敌人保存自身波次倍率，最终清空所有敌人才判胜。
- 塔库扩充到14种、28条专精；初始两种，每累计通关4个不同关卡解锁一种新塔，塔库支持分页。第48关的奖励塔用于重玩。
- 参考王国保卫战的卡通轮廓与固定塔位设计，绘制麦田、风车、绿洲、山峰、灯塔、岛礁、林木和特色单位。
- 重调难度、出生节奏、支援占比与初始资源；后期需用范围、穿甲与破盾塔应对不同攻势。
- 旧存档按关卡序号保留星级与塔组，旧版已解锁塔保留；本次地图重编，旧地名不再逐一对应。
- 32项测试通过，覆盖全部地图、叠波、解锁、地貌机制和开局及六章终关的合法经济通关模拟。
