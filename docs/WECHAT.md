当前版本为 v0.13.0 交通调度战役版。微信入口是 `wechat/`，AppID 已配置为 `wx56bc2c69040a48b6`。这是原生 Canvas 小游戏，包含六章48关；游戏运行不需要自建服务器。

## 导入与试玩

1. 打开微信开发者工具，选择导入项目，目录选本项目下的 **wechat 文件夹**，不要选择仓库根目录。
2. 确认项目类型为小游戏、AppID 正确，使用拥有该小游戏开发权限的微信登录。
3. 点击编译进入首页，选择开始游戏或读取存档，再在三个存档位中选择。进入章节地图后，点击关卡查看简报，再点击开始战斗。点地块建造，点已有炮台升级；技能、取消、暂停和声音都有屏幕按钮。
4. 点击预览，用具有权限的微信扫码进行手机测试。预览二维码会过期，过期后重新点击预览即可。

音乐与音效在首次点按后启用，可以独立关闭。各章配乐在关卡战斗中循环，建造/升级面板不打断音乐；暂停、后台及系统音频中断时停止，恢复后继续播放，并遵守已保存的音乐开关。音乐音量提高，音效适度降低；微信播放器统一设置不跟随iOS静音拨片。切到后台会暂停战斗并停止声音，返回后点击继续。通关星级与声音偏好保存在微信本地；与网页版存档不互通。当前不保存未完成战斗，重新启动会回到首页，选择读取存档可继续战役。

## 手机流程与发波规则

- 首页三个入口：开始游戏、读取存档、退出游戏。读取始终打开存档界面，空位不可读取；最多三档，显示首次建立日期、通关数、星级和待挑战关卡。新战役先选择位置，覆盖旧位置前确认。旧单存档保留在第一位，原始日期未记录时明确标注。
- 章节地图占据全宽，移除常驻右栏。关卡弹窗集中展示路线、出战四塔、初始金币、首领和变道情报；未解锁关卡可查看简报，但不能开始战斗。
- 画布覆盖整个窗口，背景延展至所有屏幕边缘。首页、章节地图、战斗控件与弹窗根据实际宽高重新布局，避开安全区和微信右上角胶囊。
- 战斗世界保留固定1280×720坐标，通过等比镜头放入可用区域；屏幕尺寸变化不修改道路、炮台位置、射程和战斗进度。
- 纸质图册配合公路路牌与六种地貌地标。未研究的进化按钮用铁链和挂锁封住，同时显示通关要求；金币不足不显示铁链。
- 建造空地使用各章的路肩、土坪、埋石、岩台、木栈台和苔地，去掉常驻方框、加号、编号，辅以小勘测桩。点选后显示金色边线与建造菜单；触控区域及可建造数量保持不变。
- 首波准备20秒；后续在上一波最后一辆车实际出场后等5–10秒，按上波数量计算：不超过10个等5秒，每多一个加0.25秒，最多10秒。出场期间圆环显示省略号与队列人数，出完后开始倒计时。
- 本波出完才可以提前迎敌，不能连续点完所有波。只在提前时奖励：剩余秒数×3向上取整，最多30G；首波也适用，到时自动发动不给额外金币。场上仍可有旧波敌人。
- 普通敌人生命提高12%、Boss提高30%；车辆造型缩小12%，增加细节，入口及跟车保留间距，被队员拦住的车辆可由后车绕行。
- 暂停、图鉴、战斗菜单和后台会冻结倒计时；倍速会同步加快战斗与倒计时。

## 交通玩法

每章八关依次循环收费站、公交、急救、桥梁四种任务，任务进度常驻顶部，简报说明目标。底部新增对应的落杆、护航、放行或抢修按钮；部分关卡另有分流按钮。1-1、2-2、3-2、4-2、5-2、6-2可以手动选择支路，其余关卡保留各自多入口或曲折路线。道路类型、弯道和重车重量影响速度。

第4/8关保留预告式路线变化，改用高架施工、隧道封闭、潮汐车道和吊桥事件。上一波开始时播放中文预告，切换前显示倒计时；已经过路口的车辆继续原路。道路、任务与调度细则见根目录README。

发动机使用一个低音播放器，距离决定音量；制动和道闸音效有频率限制。六段中文广播离线生成，包内播放，不需要联网TTS。它们均由「音效」开关控制，并随暂停、后台或音频中断停止；音乐开关独立。

## 恢复手机维护时

以下操作仅在用户明确要求恢复手机版更新后使用（需 Node.js，无需安装第三方包）；当前网页开发不执行：

```powershell
node tools/build-wechat.cjs --update-wechat
```

恢复后须重新验证两端、更新冻结清单与版本策略，再到开发者工具编译、预览。不要直接修改 `wechat/game.bundle.js`，下次生成会覆盖。当前只运行 `node --test --test-name-pattern="frozen v0.13.0" tests/wechat.test.cjs`，验证冻结的33个文件未改变。

| 文件 | 用途 |
| --- | --- |
| `src/platform/browser.js` | 网页输入、存档和音频接口 |
| `wechat/platform/wechat.js` | 微信触控、安全区、画布缩放、存档、前后台切换 |
| `wechat/platform/audio.js` | 微信音乐与音效播放器 |
| `src/core/traffic.js` | 道路速度、分流、四种任务、民用车与胜负约束 |
| `src/render/traffic.js` | 路牌、导航线、收费站、桥梁、民用车辆与任务按钮 |
| `src/render/vehicles.js` | 精细车辆、船只与地貌专用设备 |
| `src/render/mobile-art.js` | 原创纸张、地貌地标、公路路牌、按钮和铁链 |
| `src/render/mobile.js` | 固定战斗地图、关卡简报、建造/升级与研究面板 |
| `src/render/mobile-layout.js` | 全屏首页、章节地图、安全区布局、镜头和触点换算 |
| `tools/build-wechat.cjs` | 合并共享源码、生成六首配乐、十五种音效并复制六段中文广播 |
| `wechat/game.bundle.js`、`wechat/audio/` | 可直接导入的生成产物，随源码一起提交 |
| `wechat/project.config.json` | 团队共享项目配置 |

乐曲与音效由本项目代码离线合成；六段交通广播由 tools/generate-traffic-voice.ps1 使用本机 Windows 中文语音生成，现有 WAV 已包含在项目里，普通更新无需重生成。项目个人设置、临时二维码不提交到 Git。AppID 是项目标识，工程不需要 AppSecret。
